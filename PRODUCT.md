# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Recruiters, hiring managers, and potential collaborators evaluating Anas Khan as a software engineer.

## Product Purpose

A personal software engineering portfolio that presents Anas Khan's background, selected work, technical foundations, experience, and a direct way to start a conversation.

## Positioning

The portfolio demonstrates range across full-stack web development, desktop and game development while keeping the work grounded in real implementation details.

## Operating Context

Visitors browse a concise introduction, selected projects, experience, skills and achievements, then can download a resume or contact Anas directly.

## Capabilities and Constraints

The site is a Next.js portfolio. It includes a resume download, external project links, GitHub, LinkedIn, a contact form, responsive behaviour, and reduced-motion support. Existing factual project, experience, and achievement copy must be retained unless Anas changes it.

## Brand Commitments

The public identity is Anas Khan: a software engineer, full-stack developer, problem solver, and game developer. The visual language must feel credible, technically precise, and professional rather than decorative or entertainment-led.

## Evidence on Hand

Selected-project images live in `public/chat_app.png`, `public/SON.jpeg`, `public/darzi.png`, and `public/portfolio.png`. The resume is `public/Resume_AnasKhan_FAST.pdf`. Project, experience, and achievement facts are present in the source code. No metrics, client claims, or testimonials are available and must not be invented.

## Product Principles

- Make technical capability legible before visual flourish.
- Give selected work equal visibility so visitors can compare breadth quickly.
- Use motion to clarify hierarchy and progress, never as a replacement for content.
- Keep every route and contact path straightforward on desktop, mobile, and reduced-motion settings.

## Accessibility & Inclusion

Support keyboard access, visible focus states, responsive layouts, semantic content, and an intentional reduced-motion experience.
